# 🇨🇭 Assessor Fiscal · Cantó de Zúric

Eina orientativa (no oficial) per calcular deduccions fiscals a la declaració d'impostos del
cantó de Zúric. Disponible en 9 idiomes: Català, Español, English, Français, Deutsch, Italiano,
Ελληνικά, Polski, Русский.

## Ús local

No cal instal·lar res ni tenir servidor. Descarrega o clona aquest repositori i obre
`index.html` directament al navegador (doble clic).

**Totes les dades es queden només al teu navegador** (localStorage). L'aplicació no té
backend ni envia cap dada a cap servidor, encara que aquest codi estigui publicat a internet.

## Publicat a GitHub Pages

Aquest repositori es pot servir directament amb GitHub Pages (branca `main`, arrel `/`), ja
que és un lloc estàtic sense build step. Un cop activat a Settings → Pages, l'app és accessible
a la URL pública, però l'ús real segueix sent 100% local per a cada visitant.

## Avís

Aquesta eina ofereix una estimació orientativa basada en regles generals de deducció. No
substitueix el consell d'un assessor fiscal titulat ni l'ús del programari oficial
`ZHprivateTax`. Verifica sempre les xifres vigents a [zh.ch](https://www.zh.ch/de/steuern-finanzen.html).
